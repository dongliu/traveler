# Implementation Plan: Admin NCR Deletion

**Branch**: `122-admin-delete-ncrs` | **Date**: 2026-09-13 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/122-admin-delete-ncrs/spec.md`

## Summary

Allow a user with the `admin` role to select one or more NCRs from the NCR
dashboard and permanently delete them — the NCR record and every file
attached to it — in a single action, mirroring how Traveler deletion already
works in this system but additionally removing attached files (which
Traveler deletion does not do today). One new endpoint
(`DELETE /api/ncrs/:id`), authorized server-side in the service layer
(matching every other mutation in `routes/ncr.js`, not the
`reqUtils.requireAdmin()` middleware Traveler deletion uses), called once per
selected NCR from a new checkbox/toolbar selection UI on the dashboard. No
schema change, no deletion audit trail (per the spec's resolved
clarifications).

## Technical Context

**Language/Version**: JavaScript (Node.js 18+) — unchanged, extends the existing app

**Primary Dependencies**: None new — reuses Express/Mongoose, Node's built-in
`fs.promises`/`path`, and the existing `lib/role.js` admin role constant

**Storage**: MongoDB via Mongoose — no schema change; this feature deletes
existing `Ncr` documents and unlinks files already referenced by
`attachments[].file_path`

**Testing**: Mocha/Sinon/Chai (unit, `test-unit/lib/ncr-service.test.js`),
Playwright (e2e, new `e2e/us-admin-ncr-deletion.spec.js`); one new read-only
command in `e2e/fixtures/cli.js` to check file existence on disk

**Target Platform**: Linux server (Docker) — unchanged

**Project Type**: Web service (Express MVC), extends the existing NCR module

**Performance Goals**: N/A — deletion is an infrequent admin action, at most
one dashboard page (~25 rows, `state.limit` in `views/ncr-dashboard.jade`) of
small independent requests per batch

**Constraints**: Authorization MUST be enforced server-side in
`lib/ncr-service.js` regardless of what the dashboard UI shows or hides
(matches `003-originator-designate`'s identical constraint); the new route
must follow `routes/ncr.js`'s existing JSON error-envelope convention
(`mapServiceError`), not the plain-text 403 `reqUtils.requireAdmin()`
middleware returns

**Scale/Scope**: 1 user story / 7 acceptance scenarios; touches
`lib/ncr-service.js` (1 new function), `routes/ncr.js` (1 new route),
`views/ncr-dashboard.jade` (selection UI), `e2e/fixtures/cli.js` (1 new
command)
