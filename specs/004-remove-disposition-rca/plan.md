# Implementation Plan: Remove Root Cause Analysis from CE/CS Disposition

**Branch**: `004-remove-disposition-rca` | **Date**: 2026-08-22 | **Spec**: [spec.md](spec.md)

**Amends**: `specs/001-ncr-workflow` — User Story 2

## Summary

Remove the "Root Cause Analysis" section from the CE/CS disposition form and all
downstream views (NCR detail, concurrence). The `root_cause_documentation` field
in the database schema is retained for backward compatibility with existing
records but is no longer required, validated, populated, or displayed.

## Technical Context

**Language/Version**: JavaScript (Node.js 18+) — unchanged

**Primary Dependencies**: Express 4, Mongoose 7, Jade/Pug — no new dependencies

**Storage**: MongoDB via Mongoose — schema field retained, validation constraint removed

**Testing**: Mocha (unit), Playwright (e2e) — existing suites updated

**Target Platform**: Linux server (Docker) — unchanged

**Project Type**: Web service (Express MVC)

**Performance Goals**: N/A — no new queries or processing paths

**Constraints**: Backward compatibility — existing NCR documents with
`root_cause_documentation` must not crash any view

**Scale/Scope**: 7 discrete touchpoints across 5 source files + 2 test files
