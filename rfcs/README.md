# RFCs

This directory contains Request for Comments (RFC) documents for significant changes to the Traveler application.

RFCs are used to propose, discuss, and document design decisions before implementation. They are not required for small bug fixes or minor changes — use them when a feature involves non-obvious trade-offs, touches multiple parts of the system, or benefits from a written record of the rationale.

## File naming

Files are named with a sequence number prefix followed by a short description:

```
0001-traveler-file-input.md
0002-table-builder.md
```

## Structure

Each RFC document should include:

- **Summary** — what problem this solves and the proposed approach
- **Motivation** — why the current behavior is insufficient
- **Design** — detailed description of the changes
- **Drawbacks** — known trade-offs or risks
- **Alternatives** — other approaches considered
